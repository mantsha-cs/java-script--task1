# java-script--task1
 Description  This project is a simple JavaScript program that calculates the compound interest using predefined values for principal amount, rate of interest, number of times interest is compounded per year, and time. The program uses JavaScript variables, arithmetic operators, and the compound interest formula to calculate the final amount. 
# Compound Interest Calculator

## Objective
This project calculates the compound interest using JavaScript with predefined values.

## Technologies Used
- HTML
- JavaScript

## Files
- index.html (or script.html) - Main HTML file
- script.js - JavaScript logic
- README.md - Project documentation

## Variables Used
- p = Principal Amount
- r = Rate of Interest
- n = Number of times interest is compounded per year
- t = Time (in years)

## Formula
Amount = P × (1 + (R / (100 × N)))^(N × T)

## How to Run
1. Open the project folder in VS Code.
2. Open the HTML file in your browser using Live Server.
3. Open the browser Console (F12 → Console).
4. The compound interest amount will be displayed in the Console.

## Sample Values
- Principal = 20000
- Rate = 8%
- Time = 3 years
- Compounded = 1 time per year

## Output
Compound Interest after 3 years: 25194.24
